# lazydiagram

Lazy 시리즈의 다이어그램 설계 플러그인 — `lazyothers`에서 분리된 단독 레포.

## 내용

- `skills/diagram-design` — 39종 시각 타입(architecture, flowchart, sequence,
  ER, timeline, swimlane, Sankey, Wardley map, kanban, story map, DB schema 등)을
  self-contained HTML/SVG/PNG로 생성하는 스킬. `.drawio`/`.mmd` 소스 재렌더,
  웹사이트 브랜드 토큰 온보딩, 시맨틱 패턴·콜아웃·접근성 모션·스케치 스타일 지원.

## 설치

시리즈 인스톨러(`lazyothers/install.sh` / `install.ps1`)가 플러그인 목록에
포함해 함께 클론한다. 수동 설치는 다른 시리즈 플러그인과 동일하게
플러그인 디렉터리(`~/.gemini/config/plugins/`) 아래에 둔다.
